LAFA POULTRY MANAGER v1.0

FEATURES
- Multiple incubation batches
- Automatic Day 8 candling reminder
- Day 18 transfer/lockdown reminder
- Day 21 hatch reminder
- Day 22 chick removal reminder
- Candling assistant using observed signs: veins, embryo/dark mass, movement, clear egg, blood ring
- Candling counts: Fertile / Infertile / Suspect
- Chick growth batches
- Day 7 Newcastle I
- Day 14 Gumboro I
- Day 21 Newcastle II
- Day 28 Gumboro II
- Day 35 Fowl Pox
- Adult booster reminders every 3 months (8 future boosters scheduled)
- Local notification alarms at 07:00 Africa/Dar_es_Salaam
- Data saved on the phone

HOW TO BUILD ON WINDOWS
1. Extract this folder.
2. Double click BUILD_APK_NOW.bat
3. When complete, copy LAFA-Poultry-Manager.apk to your Android phone and install it.

IMPORTANT
Candling Assistant is a decision-support heuristic, not a camera AI detector and not 100% accurate. Use proper candling technique and local poultry/veterinary guidance.
